# HraELL 0.1

HraELL is based on Vector and includes a simplified manager interface, revised logging controls, external browser links, and its own crossed-bandage icon.

Builds are currently distributed through [GitHub Actions](https://github.com/ForgetWolf/HraELL/actions/workflows/core.yml). No stable release is advertised by the module updater yet. When a release is published, update `zygisk/update.json` with its actual version code and ZIP URL.
